# 科学实验录像叠加工具

把合成传感曲线、当前读数和事件标记烧录到实验视频。数据与画面之间的时间
关系通过**人工锚点**建立，时钟误差以**范围**说明；网页可调整时间偏移、
速率与显示布局，后端保存视频时间戳、数据采样时刻、单位与对齐锚点。

## 原则

- **行号不是帧号**：传感数据按各自的时间戳检索；视频帧号只经
  `frame/fps` 换成视频时钟秒，再经锚点拟合的 `data_t = rate·video_t + offset`
  映射到数据时钟。
- **缺测不造假**：每个字段独立配置重采样方式（线性/保持）与最大缺口。
  超过限度的缺口、记录范围之外、时钟回退区间，一律显示缺测（曲线断开、
  文字显示 `—`、回退区显示 `rollback`），不用直线填满。
- **同帧同刻**：每帧只计算一次 `data_time`，曲线窗口与数值文字都引用它；
  逐帧清单（manifest.csv）记录同一值，可逐帧核对。
- **修订产生新候选**：渲染 id = 全部参数（含数据版本哈希、锚点哈希）的
  哈希。数据修订（v1→v2：单位 kPa→hPa、偏置修正、回退修复）生成新的
  候选渲染；已导出版本是目录级冻结副本，永不覆盖，可复现。
- **不同步不装精确**：对齐误差以覆盖全部锚点的残差范围显示在画面顶部与
  清单中，不宣称超出锚点证据的精度。

## 运行

```bash
# 生成演示实验（源视频+两个数据版本+锚点），渲染候选、导出、QC
.venv/bin/python -m overlay_tool.demo projects/demo

# 启动网页（调整时间关系与布局，触发渲染/导出；可在左侧拖动时间预览）
.venv/bin/python -m overlay_tool.app --project projects/demo --port 8000
# 打开 http://127.0.0.1:8000

# 测试（默认跳过慢速基准；-m benchmark 单独完整运行数据取样成本）
.venv/bin/python -m pytest tests/
.venv/bin/python -m pytest tests/ -m benchmark

# 时基查询基准：成本分解 + 五级负载 + 稀疏化偏差
.venv/bin/python -m overlay_tool.benchmark --out results/time_base_benchmark.json
```

## 拖动预览与可失效时间索引

长视频反复拖动时间时，旧路径每次都重新解析观测表并线性扫描定位样本。
现在由 `time_index.py` 把每个数据版本解析一次为 `TimeIndex`（排序时间戳、
二分/游标定位、回退区间预算），`scrub.py` 通过 `/api/preview` 提供两类**分离**
的结果：

- **显示曲线**（`field_curve`）：窗口内观测样本经分块 min/max 稀疏化为
  ≤120 点折线，缺测段与回退段仍以红/黄色块按原解释着色，不用直线填满。
  稀疏化只影响绘制，**绝不参与叠加或清单中的数值**。
- **精确取值**（`exact_reading`）：与渲染器、`manifest.csv` 同源的
  `SeriesSampler` 语义（线性/保持、最大缺口、回退 ambiguous、范围外 missing），
  单位换算后单独返回；非单调或缺测段的解释保持不变。

索引按「项目 + 版本 + 文件 sha256」注册在进程级 `TimeIndexRegistry` 中。
同名数据文件被修订后，指纹变化即失效旧条目，只服务当前素材版本；也可显式
`invalidate()`。后台渲染任务在启动前与发布前各核对一次素材指纹（数据 sha256
与锚点 sha256），期间素材变更则标记 `stale`、不发布清单。

## 数据取样成本（时基查询基准）

`overlay_tool/benchmark.py` 对同一组时基查询比较两条实现，负载按**观测更密、
缺测段更长**逐级增加（L1 稀疏 → L5 密集且长缺口，每级保留时钟回退结构）：

- 基线（旧顺序）：每次查询 `解析 JSON/排序/回退区间 → 线性定位 → 重采样取值`；
- 优化（新顺序）：`一次性建索引 → 二分（或单调游标）定位 → 同一重采样取值`；
  显示折线构建是额外的独立路径，其稀疏值不替换精确读数。

**计算顺序变化说明**：解析与回退区间计算从「每查询一次」提前到「每素材版本
一次」；定位从全表线性扫描改为二分/游标；重采样公式、缺口判定、回退判定与
单位换算的内部顺序完全未动。每次运行逐级记录定位耗时、取值耗时和稀疏折线对
精确值的偏差（显示单位与归一化百分比）。状态不一致（missing/ambiguous 漂移）
或数值与基线不符即退出码 1——出现定位耗时与数值偏差之外的行为退化时，撤回
对应的数据取样优化（优化代码集中在 `time_index.py`，精确取值路径可直接回退到
`SeriesSampler`）。最近一次报告见 `results/time_base_benchmark.json`。


## 演示场景

摄像机拍摄转台与刺激 LED（相机烧录时钟比视频时间轴慢 2 s）。LED 在
视频时刻 2.5/7.0/11.5/16.0 s 闪光；记录仪在自己的时钟（偏移 +1.35 s）
下记录脉冲、温度（非等距 0.3–0.9 s，10–14 s 掉线）与压力（非等距
约 10 Hz，物理 15.4–16.6 s 被误盖成 13.8–15.0 s 的时间戳）。记录于
数据时刻 18.0 s 停止，视频走到 20 s —— 片尾 3.4 s 无数据。

数据 v2 是事后修订：压力重定标 +2% 并改用 hPa，温度修正 −0.3 °C 偏置，
压力时间戳经缓冲诊断修复。

## 交付物（projects/demo/）

| 文件 | 说明 |
|---|---|
| `source.mp4` / `source_meta.json` | 合成源视频与视频时间戳参数 |
| `data/v1.json` `data/v2.json` | 两个数据版本（采样时刻、值、单位、元数据） |
| `anchors.json` | 人工锚点（闪光帧 ↔ 数据脉冲） |
| `render_params.json` | 参数工程：偏移/速率/逐字段重采样/布局 |
| `renders/<id>/overlay.mp4` | 候选渲染视频 |
| `renders/<id>/manifest.csv` | **逐帧读数清单**：帧号、视频时刻、数据时刻、各字段显示值/状态/单位、事件标志 |
| `renders/<id>/manifest.json` | 参数快照 + QC 统计 + 对齐范围 |
| `exports/<id>/` | 冻结导出（含以上全部 + export.json），不可变 |
| `qc_report.json` | 闪光↔脉冲样例等 12 项核对结果 |

## 核对方法

1. **偏移与采样**：`qc_report.json` 用 4 对闪光↔脉冲样例检查拟合偏移
   落在真值 ±0.05 s 内、每个闪光帧的清单行 `stim_pulse_active=1`。
2. **逐帧读数**：任取清单一行，按 `data_time_s` 在 `data/vX.json` 中
   用相邻样本插值，结果应等于清单中的显示值（缺口/回退/片尾行应为
   缺测状态）。
3. **可复现**：用同一 `render_params.json` 重渲染，渲染 id 相同，
   `manifest.csv` 字节一致；`exports/` 中的旧版本不受新渲染影响。
